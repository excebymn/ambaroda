Taruh gambar kepala di folder ini (PNG transparan, persegi, misal 128x128, menghadap kanan):
  normal.png  -> kepala saat lari
  hit.png     -> kepala saat kena hit (opsional, kalau tidak ada dipakai normal.png)
  dead.png    -> kepala saat game over (opsional, kalau tidak ada dipakai normal.png)
Kalau normal.png belum ada, game memakai kepala bulat coretan sebagai pengganti.
